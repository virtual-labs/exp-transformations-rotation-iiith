Instructions
  1. Mouse Controls:
    • Left Mouse: Used for translating (shifting) the entire simulation by left-clicking and dragging the cursor.
    • Right Mouse: Used for rotating the simulation by right-clicking and dragging the cursor.
    • Middle Mouse: Used for zooming in and out of the simulation by scrolling.
  2. Lock Options:
    • Lock Graph: Disables the translation (shifting) of the simulation when enabled.
    • Lock Zoom: Prevents zooming functionality when enabled, disabling the middle mouse button.
    • Lock Rotate: Disables the rotation of the simulation when enabled, disabling the right mouse button.
  3. Shape Controls:
    • Click the Add button to open a modal where you can select a shape type and specify the coordinates for positioning.
      • Note:⚠️ Do not create any two shapes with the same coordinates.
    • Click the Select button to choose a shape, which will highlight it with a spherical outline in the scene for easy identification.
      • After selecting, click the Edit button to modify the shape's properties or position.
      • After selecting, click the Delete button to remove the shape from the scene.
  4. Rotation Controls:
    • Select Rotation Axis: Choose X, Y, or Z from the dropdown to define the axis of rotation.
    • Apply Rotation: Click the Change Axis button to set the selected axis for rotation.
    • Adjust Rotation: Use the Slider to adjust the angle of rotation dynamically.
    • Theta (θ): Defines the rotation angle. Enter a value in degrees (e.g., 90°, 180°) to rotate the shape, or adjust it with the slider.
  5. NOTE:
    • For Points: Rotation occurs around the X, Y, and Z axes passing through the origin.
    • For Shapes: Rotation occurs around axes passing through their center in the X, Y, and Z directions.
  6. Grid Options: Check the corresponding checkboxes to display the XY-grid, YZ-grid, and XZ-grid, and uncheck them to remove them from view.
  7. Frames: Set the number of frames to control how smoothly the object moves from one point to another.
  8. Point Coordinates: Defines the specific position of a point in 3D space using the X, Y, and Z axes.
